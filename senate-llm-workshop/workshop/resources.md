# Resources

Tools, databases, and references for continued practice after the workshop.

---

## This Repository as a Resource

The knowledge base in this repository is designed to be copied directly into any LLM conversation as context. Here is what each folder contains and how to use it:

**catalog/** — Academic program structures generated from curricular-sequence data. Content is in Spanish (SmartCatalog source). Use these files when asking an LLM to analyze program structures, compare requirements, or audit curricula against market data.

- `gen-ed-requirements.md` — General education requirements for bachelor and associate degrees.
- `programs-business-1.md` — Business programs part 1: Accounting, Finance, Management, International Business, Real Estate, Office Systems.
- `programs-business-2.md` — Business programs part 2: Marketing, HR, Hospitality, Tourism, Music, Sports, Security.

**institutional/** — Curated institutional context from public federal sources.

- `enrollment-data.md` — Enrollment trends 2020–2024, demographics, graduation rates. All from IPEDS. This is the most useful single file for institutional analysis.

**data/** — Raw reference data.

- `CSV_182026-218.csv` — Full IPEDS data export with 90+ variables.
- `accounting-positions-1-2026` — Compiled job market analysis of Puerto Rico accounting positions with skill frequencies.

### How to use

1. Open any LLM (ChatGPT, Claude, Gemini, Copilot, or another).
2. Start a conversation or project.
3. Copy or attach one or more knowledge base files as context.
4. Use the prompt templates from the quick reference or prompt guide.

The files are structured to be independently useful — you do not need all of them for any single analysis.

## Institutional Planning and Analysis

- [IPEDS Data Center](https://nces.ed.gov/ipeds/datacenter/) — Compare your institution to peers on enrollment, graduation rates, finances, and more. Free federal data.

## Curriculum and Labor Market

- [Bureau of Labor Statistics](https://www.bls.gov/) — Employment projections, occupation data, and wage statistics. Occupational Outlook Handbook is the starting point.

## Grant Resources

- [Grants.gov](https://www.grants.gov/) — Central database for all federal grant opportunities. Set up saved searches by agency and keyword.
- [NSF Funding Opportunities](https://www.nsf.gov/funding/) — STEM and research grants. HSI-specific programs are particularly relevant.

## LLM Platforms

Brief, non-endorsement descriptions. Each platform has free and paid tiers with different capabilities.

**ChatGPT** (OpenAI) — The most widely used. Free tier available. Paid tiers offer file uploads, longer context, and custom GPTs. Strong general-purpose performance.

**Claude** (Anthropic) — Strong at long document analysis and nuanced writing. Projects feature allows persistent context files. Free tier available.

**Gemini** (Google) — Integrated with Google Workspace. Useful for users already in the Google ecosystem. Free tier available.

**Copilot** (Microsoft) — Integrated with Microsoft 365. Useful for users already in the Microsoft ecosystem. Free tier available with limited features.

For institutional work, the choice of platform matters less than the quality of context you provide. The prompt guide and knowledge base files in this repository work with any of these platforms.

## Recursos — En Español

### Este Repositorio

Las carpetas `catalog/`, `institutional/` y `data/` contienen datos estructurados sobre Inter Metro. Los archivos están diseñados para copiarse directamente en cualquier conversación con un LLM como contexto. El archivo más útil para empezar: `institutional/enrollment-data.md`.

### Herramientas Clave

- **IPEDS Data Center** — Datos federales de matrícula, tasas de graduación y finanzas. Gratis.
- **Bureau of Labor Statistics** — Proyecciones de empleo y datos salariales por ocupación.
- **O*NET Online** — Perfiles ocupacionales detallados: destrezas, conocimientos y tecnología requerida.
- **Grants.gov** — Base de datos central de oportunidades de becas y fondos federales.

### Plataformas de LLM

La elección de plataforma importa menos que la calidad del contexto que proporcionas. Los archivos de la base de conocimiento de este repositorio funcionan con cualquier plataforma: ChatGPT, Claude, Gemini, Copilot, u otra.
